# Contribution Guidelines

## Adding something the list

### Contribution criteria

Contributions are encouraged to add any resources to the list, given that they are:

1. on the topic of critical thinking and
2. you think they should be recommended ("are awesome").

Furthermore, items will only be accepted after peer-review of quality, if they are formatted correctly and if they are put
in what is deemed by a maintainer to be the most appropriate sub-section of the list:

* use the existing list entries as a guide, and be consistent with those, specifically:
  * use the name of the resource with appropriate capitalisation and attribution,
  * have this hyperlinked to the resource itself if online, or for a book to the Goodreads page for it
  * and then follow this with a space, a hyphen (`-`), then a single concise sentence describing the resource and ideally
    including an indication as to why it is so good as to recommend;
* think carefully about which heading sub-section of the list they are most suitable to go under.


### How to make a contribution

If you have something you wish to contribute to the list, this is one way you can do it (via the GitHub browser UI):

0. You will need a [GitHub account](https://github.com/join)! If you are new to GitHub, [get started here](https://github.com/firstcontributions/first-contributions).
1. Access the `awesome-critical-thinking` list GitHub page: https://github.com/sadielbartholomew/awesome-critical-thinking
2. Click on the `README.md` file.
3. Now click on the edit icon.
4. You can start editing the text of the file in the in-browser editor. Make sure you follow the guidelines above. You can use [GitHub Flavored Markdown](https://help.github.com/articles/github-flavored-markdown/).
5. Say why you're proposing the changes, and then click on "Propose file change".
6. Submit the [Pull Request](https://help.github.com/articles/using-pull-requests/)!

## Updating your Pull Request

A maintainer may ask you to edit your Pull Request before it is included. This is normally due to spelling errors or because your PR didn't match the awesome-* list guidelines.

[Here](https://github.com/RichardLitt/knowledge/blob/master/github/amending-a-commit-guide.md) is a write up on how to change a Pull Request and the different ways you can do that.
